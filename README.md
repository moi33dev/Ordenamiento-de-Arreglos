# 🔢 Bubble Sort Algorithm in PHP

Este proyecto es una implementación del algoritmo de ordenamiento de burbuja (Bubble Sort) desarrollado en PHP. El objetivo es demostrar lógica de programación, manejo de arreglos y optimización de algoritmos básicos.

## 📝 Descripción
El algoritmo recorre un arreglo de números, comparando elementos adyacentes e intercambiándolos si están en el orden incorrecto. Este proceso se repite hasta que el arreglo esté completamente ordenado.

## 🛠️ Tecnologías
* **Lenguaje:** PHP 8.x
* **Interfaz:** HTML5 / CSS3 (para la visualización de los resultados)

## 🚀 Características
- **Lógica de Intercambio:** Implementación manual sin el uso de funciones nativas de PHP como `sort()`.
- **Visualización:** Estilizado con CSS para mostrar el "Antes" y "Después" del arreglo.
- **Complejidad:** Incluye comentarios sobre la complejidad temporal O(n²).

## 📂 Cómo ejecutarlo
1. Clona este repositorio o descarga los archivos.
2. Coloca la carpeta en tu servidor local (XAMPP, Laragon, etc.).
3. Accede desde tu navegador a `http://localhost/tu-carpeta/index.php`.
